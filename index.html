A local row cache inside PostgreSQL

Keep ordinary SQL. Cache complete rows by primary key. Fence affected entries before commit visibility.

Ordinary SQL

Supported primary-key reads need no cache-specific driver or query API.

Whole rows

Complete tuples keyed by the table primary key.

Transaction-aware invalidation

Source writes fence affected entries before commit visibility.

Bounded extension memory

Deterministic extension allocations are bounded at startup; host limits remain separate.

Three SQL paths, one workload

The SQL-only runner keeps the schema, rows, query, role, PostgreSQL version and client settings fixed.
